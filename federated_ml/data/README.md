# FloraVeda — Dataset Directory

This directory holds the plant disease images used for federated training.

## Structure

```
data/
├── raw/              ← Place downloaded dataset here
│   ├── ClassName1/
│   │   ├── img001.jpg
│   │   └── ...
│   ├── ClassName2/
│   │   └── ...
│   └── ...
├── processed/        ← Generated by prepare_data.py (validated images)
│   └── ...
└── clients/          ← Generated by create_clients.py (partition mapping)
    └── partition.json
```

## Obtaining the Dataset

### Option 1: PlantVillage (Recommended)
- **Source**: https://www.kaggle.com/datasets/emmarex/plantdisease
- **Size**: ~3 GB, 38 classes, ~54,000 images
- Download and extract into `data/raw/`

### Option 2: Custom Dataset
- Organize images into class-named subdirectories under `data/raw/`
- Each subdirectory = one disease class
- Minimum image size: 64×64 pixels
- Supported formats: .jpg, .jpeg, .png, .bmp, .tiff, .webp

## Privacy Note

These images are used ONLY for simulated local client training.
In a real federated deployment, each client's images would remain
on their own device and never be uploaded to a central server.
